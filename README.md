# 규칙 기반 감성 분석과 정보 추출

## 설치 및 실행

프로젝트 루트에서 다음 명령을 실행한다. 지원 환경은 Intel macOS와 Linux x86_64이며, 아래 명령은 Python 3.12를 기준으로 한다.

```bash
python3.12 codyssey_4_2_nlp_environment.py
source data/activate.sh
python src/korean_sentiment.py         # 영화 리뷰의 감성 점수와 계산 근거
python src/information_extractor.py    # 샘플 문장의 정규화·마스킹 결과
python -m unittest discover -s tests   # 회귀 테스트
```

첫 번째 명령은 가상환경, JDK, Python 패키지, 분석용 사전과 데이터셋을 준비하고 설치 상태를 검증한다. 두 번째 명령은 현재 셸에 실행 환경을 적용한다. 노트북 실행 시 프로젝트의 `.venv/bin/python`을 커널로 선택한다. [Python 패키지 버전](requirements.txt)

정보 추출기에 직접 문장을 전달하려면 `python src/information_extractor.py "일시 2024/3/15, 참가비 50,000원."`을 실행한다. 기대 결과는 날짜 `2024-03-15`와 금액 `50000`이다. 개인정보는 기본적으로 마스킹하며, 예시 입력의 정규화 결과만 확인할 때는 `--no-mask`를 사용한다.

학습 리뷰에서 형태소·품사별 총출현 횟수와 해당 표현이 등장한 리뷰 수를 각각 집계했다. KNU 미등록 표현을 추출한 뒤, 학습 표본의 긍정·부정 리뷰별 출현 비율과 실제 용례를 검토해 채택 여부와 점수를 결정했다.

| 선정 표현 | 긍정 리뷰 출현 건수 | 부정 리뷰 출현 건수 | 부여 점수 | 선정 근거 |

| 명작 | 221 | 26 | +2 | 작품에 대한 강한 호평 |

## 3. 감성 점수 산출

리뷰에서 형태소와 품사가 사전 항목과 일치하는 표현을 찾는다. 동일한 위치에서 여러 항목이 일치하면 가장 긴 표현을 선택한다. 규칙 적용 시 부정 횟수가 홀수이면 점수의 부호를 반전하고, 강도 조절 표현이 있으면 해당 배율을 곱한다.

예문 “정말 명작! 전개는 조금 뻔했어요.”의 계산 결과는 다음과 같다.

| 사전 표현 | 기본 점수 | 강도 조절 | 반영 점수 |
|---|---:|---|---:|
| 명작 | +2 | 정말 × 1.5 | +3.0 |
| 뻔하다 | −1 | 조금 × 0.5 | −0.5 |

합계는 **+2.5점**이며 판정은 **긍정**이다. 이진 분류 기준은 0점 초과를 긍정, 0점 이하를 부정으로 한다. 감성 표현이 검출되지 않거나 양수와 음수가 상쇄된 리뷰도 0점으로 처리한다.

## 4. 성능 평가

NSMC 테스트 데이터에서 긍정·부정 리뷰를 각각 500건씩 추출했다(난수 시드 42). 동일한 1,000건에 대해 사전 종류와 규칙 적용 여부를 조합한 네 조건을 비교했다. Macro F1은 긍정·부정 클래스별 F1의 평균이며, 매칭률은 사전 표현이 하나 이상 검출된 리뷰의 비율이다.

| 감성사전 | 부정·강조 규칙 | 정확도 | Macro F1 | 매칭률 |
|---|---|---:|---:|---:|
| KNU 원본 | 미적용 | 67.9% | 0.678 | 84.7% |
| KNU 원본 | 적용 | 68.2% | 0.681 | 84.7% |
| 도메인 확장 | 미적용 | 69.7% | 0.696 | 86.7% |
| **도메인 확장** | **적용** | **70.2%** | **0.701** | **86.7%** |

동일한 규칙을 적용했을 때 사전 확장으로 **정확도가 68.2%에서 70.2%로 2.0%p 상승했다.** 기존 오답 27건이 정답으로, 기존 정답 7건이 오답으로 변경됐다. 예를 들어 긍정 리뷰 “여운이 남는영화...”는 ‘여운’ 추가로 0점에서 +1점으로 변경되어 정답으로 분류됐다. 최종 조건에서 0점으로 부정 판정을 받은 리뷰는 221건이었다.
