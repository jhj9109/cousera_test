# 규칙 기반 정보 추출과 감성 분석의 정밀도·재현율

- **정보 추출** — 직접 작성한 108문장에서 정밀도 **89.9%**, 재현율 **80.8%**. 금액처럼 형식이 엄격한 유형에서 오탐은 적지만 표기 변형을 놓치는 경향
- **감성 분석** — NSMC 리뷰 1,000건에서 영화 표현 51개와 부정·강조 규칙을 함께 사용했을 때 **긍정 정밀도 72.25%, 긍정 재현율 65.6%**. 네 조건 중 두 지표 모두 최고
- **지표 읽기** — 정밀도는 ‘찾았다고 한 것 중 정답 비율’, 재현율은 ‘찾아야 할 정답 중 실제로 찾은 비율’. 정보 추출의 정답 단위는 **유형과 위치가 일치하는 원문 구간**, 감성 분석의 정답 단위는 **긍정 리뷰 한 건**

## 감성 분석 — 사전 확장과 문맥 규칙의 효과

- **비교 조건** — 동일한 긍정 500건·부정 500건 사용. 총점이 0을 초과하면 긍정, 0 이하면 부정. [05 평가 노트북](../notebooks/05_korean_sentiment_scoring_evaluation.ipynb) · [조건별 원자료](../data/outputs/sentiment_evaluation/metrics_v001.csv)

| 감성사전 | 부정·강조 규칙 | 긍정 정탐(TP) | 긍정 오탐(FP) | 긍정 미탐(FN) | 긍정 정밀도 | 긍정 재현율 |
|---|---|---:|---:|---:|---:|---:|
| KNU 원본 | 미적용 | 314 | 135 | 186 | 69.93% | 62.8% |
| KNU 원본 | 적용 | 320 | 138 | 180 | 69.87% | 64.0% |
| 영화 표현 51개 추가 | 미적용 | 323 | 126 | 177 | 71.94% | 64.6% |
| 영화 표현 51개 추가 | 적용 | 328 | 126 | 172 | **72.25%** | **65.6%** |

- **사전 확장 효과** — 규칙 적용 여부를 고정하면 두 경우 모두 정밀도·재현율 상승. 규칙 적용 상태에서 긍정 정탐 8건 증가, 오탐 12건 감소. 예컨대 “여운이 남는영화...”는 ‘여운’ 추가로 0점에서 +1점이 되어 긍정 리뷰를 회수. [리뷰별 판정 변화](../data/outputs/sentiment_evaluation/review_scores_v001.csv)
- **부정·강조 효과** — 원본에서는 긍정 정탐 6건 증가와 함께 오탐도 3건 증가해 정밀도 소폭 하락. 확장 사전에서는 오탐 수가 126건으로 같고 정탐이 5건 늘어 두 지표 모두 상승. 부정과 강조는 함께 켠 조건으로 평가해 개별 효과는 분리하기 어려움
- **재현율의 한계** — 최종 조건에서 놓친 긍정 리뷰 172건 중 88건이 0점. 사전에서 근거를 찾지 못하거나 긍정·부정 점수가 상쇄되면 이진 판정 정책상 긍정을 놓침

## 정보 추출 — 엄격한 형식과 추출 경계의 효과

- **비교 조건** — 9개 유형별 12문장. 전체 수치는 유형별 TP·FP·FN을 합산한 마이크로 평균. [07 유형별 집계와 실패 원문](../notebooks/07_information_extraction_evaluation.ipynb)

| 정보 유형 | 정밀도 | 재현율 |
|---|---:|---:|
| 이메일 | 90.9% | 83.3% |
| 전화번호·날짜·카드 (각각) | 90.0% | 81.8% |
| 금액 | 100.0% | 63.6% |
| URL | 72.7% | 72.7% |
| 주민번호·API 키 (각각) | 90.9% | 90.9% |
| 주소 | 100.0% | 80.0% |
| **전체 (TP 80, FP 9, FN 19)** | **89.9%** | **80.8%** |

- **금액** — 추출한 7건은 모두 정답이지만 전체 정답 11건 중 4건 누락. ‘5000원입니다’는 뒤의 한글 경계에서, ‘1.5억원’은 원화 정수 검증에서 제외. 높은 정밀도와 낮은 재현율이 함께 나타난 사례
- **URL** — 주소 뒤의 조사까지 포함하거나 경로의 괄호 앞에서 추출을 중단. 구간 경계가 어긋나면 잘못 찾은 구간은 오탐 1건, 놓친 정답 구간은 미탐 1건으로 집계
- **규칙 변경의 판단 기준** — 정보 추출은 허용 형식을 넓힐 때 새로 생기는 오탐까지 확인. 감성 분석은 사전 추가와 문맥 규칙을 각각 고정해 개선 원인을 구분하고, 새로 맞힌 리뷰와 새로 틀린 리뷰를 함께 검토
