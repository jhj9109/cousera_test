# 미션 4-2 — 분류 및 정보 추출 평가 지표

감성 분석과 정보 추출 평가에 사용하는 **정확도(Accuracy), 정밀도(Precision), 재현율(Recall), F1 Score**를 정리한다.

## 1. TP / FP / TN / FN

이진 분류에서 **Positive는 탐지 대상으로 정한 클래스**다. 감성 분석에서 긍정을 Positive로 정의한 경우를 가정한다.

| 실제 \ 예측 | 긍정(Positive) | 부정(Negative) |
|---|---|---|
| **긍정(Positive)** | **TP** — 긍정을 긍정으로 맞힘 | **FN** — 긍정을 부정으로 잘못 판단 |
| **부정(Negative)** | **FP** — 부정을 긍정으로 잘못 판단 | **TN** — 부정을 부정으로 맞힘 |

- **True / False**: 예측이 실제 정답과 일치하는지 여부
- **Positive / Negative**: 시스템이 어떤 클래스로 예측했는지 구분

### 계산 예시: 리뷰 100개

| 실제 \ 예측 | 긍정 | 부정 | 합계 |
|---|---:|---:|---:|
| 긍정 | TP = 30 | FN = 20 | 50 |
| 부정 | FP = 10 | TN = 40 | 50 |
| 합계 | 40 | 60 | 100 |

## 2. 주요 평가 지표

| 지표 | 공식 | 위 예시의 결과 | 평가하는 질문 |
|---|---|---:|---|
| **정확도 (Accuracy)** | `(TP + TN) / (TP + FP + FN + TN)` | **70%** = 70/100 | 전체 예측 중 얼마나 맞혔는가? |
| **정밀도 (Precision, P)** | `TP / (TP + FP)` | **75%** = 30/40 | 긍정이라고 예측한 것 중 실제 긍정은 얼마나 되는가? |
| **재현율 (Recall, R)** | `TP / (TP + FN)` | **60%** = 30/50 | 실제 긍정 중 얼마나 찾아냈는가? |
| **F1 Score** | `2PR / (P + R) = 2TP / (2TP + FP + FN)` | **66.7%** = 60/90 | 정밀도와 재현율을 함께 고려하면 어느 정도인가? |

> 분모가 0인 경우에는 별도의 처리 정책을 정해야 한다.

### 정밀도와 재현율의 차이

- **정밀도**: *찾은 것*의 정확성. FP(잘못 탐지)를 줄이는 데 초점.
- **재현율**: *찾아야 할 것*의 발견 비율. FN(누락)을 줄이는 데 초점.
- 조건을 엄격하게 설정하면 FP가 줄어 정밀도가 높아질 수 있지만, 정상 대상까지 놓쳐 재현율이 낮아질 수 있다. 반대 상황도 가능하다.
- **F1**은 정밀도와 재현율의 **조화평균**으로, 한쪽이 낮을 때 함께 낮아진다.

## 3. 추가 지표

| 지표 | 공식 | 의미 | 위 예시 |
|---|---|---|---:|
| **특이도 (Specificity, TNR)** | `TN / (TN + FP)` | 실제 부정 중 부정으로 맞힌 비율 | **80%** |
| **거짓 양성률 (FPR)** | `FP / (FP + TN)` | 실제 부정 중 긍정으로 잘못 분류한 비율 | **20%** |
| **거짓 음성률 (FNR)** | `FN / (FN + TP)` | 실제 긍정 중 놓친 비율 | **40%** |
| **Fβ Score** | `(1 + β²)PR / (β²P + R)` | 정밀도·재현율에 서로 다른 가중치를 적용 | β에 따라 달라짐 |

- `β = 1`: F1 Score.
- `β > 1`: 재현율을 상대적으로 더 중시.
- `0 < β < 1`: 정밀도를 상대적으로 더 중시.

## 4. 정확도만으로는 충분하지 않은 이유

리뷰 1,000개 중 **긍정 990개, 부정 10개**라고 가정한다. 모델이 모두 긍정으로 예측하면:

- **정확도 = 99%** (990/1,000)
- **부정 리뷰에 대한 재현율 = 0%** (10개 중 0개 탐지)

즉, 클래스가 불균형하면 높은 정확도가 소수 클래스에 대한 성능을 보장하지 않는다.

## 5. 미션 4-2 적용

| 과제 | 요구 지표 | 관찰 대상 |
|---|---|---|
| **정보 추출** | Precision, Recall | 올바르게 추출했는가? 잘못 추출하거나 놓친 대상은 무엇인가? |
| **감성 분석** | Accuracy, F1 Score | 문장별 감성을 얼마나 정확하게 분류했는가? |

### 정보 추출 평가의 주의점

정보 추출은 단순히 대상이 **있는지**만 판단하는 것보다 추출 개체의 **종류·위치·정규화 값**이 일치하는지 평가하는 방식이 일반적이다.

예시: 정답은 `abc@test.com`인데 `xyz@test.com`을 추출했다면:

- **FP +1**: 잘못된 이메일을 추출함.
- **FN +1**: 실제 이메일을 추출하지 못함.

정보 추출에서는 전체 비대상 후보를 정의하기 어려워 **TN을 집계하지 않는 경우가 많다**. 이때는 TP·FP·FN으로 Precision·Recall을 계산한다.

### 감성 분석 평가의 주의점

- **Positive 클래스(긍정인지 부정인지)**를 명시해야 Precision, Recall, F1을 정확히 해석할 수 있다.
- 긍정·부정 양쪽 성능을 함께 평가하려면 클래스별 F1과 **Macro F1**(클래스별 F1의 산술평균)을 살펴볼 수 있다.
- 중립을 별도 클래스로 두는 다중 분류에서는 클래스별 One-vs-Rest 방식으로 TP·FP·FN·TN을 정의할 수 있다.

## 핵심 요약

- **Accuracy:** 전체 예측 중 정답 비율
- **Precision:** 예측한 Positive의 정확성 — `TP / (TP + FP)`
- **Recall:** 실제 Positive를 찾아낸 비율 — `TP / (TP + FN)`
- **F1:** 정밀도와 재현율의 균형 — `2PR / (P + R)`

**기억법:** 정밀도는 *찾은 결과의 정확성*, 재현율은 *놓치지 않고 찾은 정도*를 묻는다.
